PBAS System Tools and Technologies

Frontend and Backend Technical Stack with Versions

1. System Architecture

PBAS, Budget Automation System, is built as a web-based system with a separate frontend and backend. The frontend is a React single page application, while the backend is a Ruby on Rails REST API. The frontend communicates with backend APIs under the /api/v1 namespace.

Layer Technology Purpose
Frontend React with Vite User interface, forms, dashboards, reports, routing, and API communication.
Backend Ruby on Rails API Business logic, authentication, database operations, validations, and reports APIs.
Database SQLite in current development configuration Stores users, requests, budgets, payroll, estimates, internal revenue, audit logs, and notifications.
Authentication JWT and bcrypt Secure login tokens and password hashing.

4. Main System Modules

  • Dashboard: Shows summary of system data and quick status information.
  • User Management: Handles users, roles, activation/deactivation, and account management.
  • Resource Request Management: Handles request creation, verification, approval, rejection, and tracking.
  • Budget Management: Handles budget heads, categories, allocations, utilization, and remaining budget.
  • Payroll Management: Stores staff payroll data, allowances, deductions, gross pay, net pay, and active/inactive status.
  • Estimates Management: Shows estimates, including payroll estimates fetched from payroll data.
  • Internal Revenue: Stores revenue entries and non-public fund entries with receipt/cutting impact.
  • Reports: Presents budget, payroll, request, and revenue related reporting data.
  • Audit Logs: Tracks important system actions for accountability.
  • Settings: Handles profile, password, image, and account related settings.
  • Notifications: Shows system notifications and unread/read state.
  • Authentication: Includes signup, login, email verification, forgot password, and reset password flows.

5. Reports and Charts Technique

The current frontend dependency list does not include a separate chart library such as Recharts or Chart.js. Reports and dashboard visual information are created using React components, Ant Design UI components, tables, cards, progress indicators, filters, CSS styling, and backend API data aggregation.

6. Backend API Coverage

The backend exposes API controllers for sessions, registrations, password reset, email verification, users, workflow requests, budgets, budget heads, budget categories, payrolls, payroll staff, payroll estimates, internal revenue, dashboard, reports, audit logs, notifications, invitations, and profile settings.

Summary: PBAS uses React, Vite, Ant Design, Redux Toolkit, and React Router on the frontend. The backend uses Ruby on Rails API with JWT authentication, bcrypt password hashing, SQLite development database, Rails migrations, REST controllers, and automated tests.
